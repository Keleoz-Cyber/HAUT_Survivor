## 项目简介

**HAUT Survivor**（河南工业大学幸存者）是一款以河南工业大学莲花街校区为背景的**周回合制大学生模拟器**。

你将扮演一名大学生，在一个 16 周的学期中做出各种选择——上课、摸鱼、社交、参加社团、挑战副本、结识 NPC——最终走向属于你的学期结局。

核心体验：

```
创建角色 → 每周消耗行动点探索/社交/学习 → 周总结 → 16 周后学期结局
```

## 快速开始

### 本地运行

需要 MySQL 8 和 JDK 17+。

1. 创建数据库：`CREATE DATABASE IF NOT EXISTS haut_survivor DEFAULT CHARACTER SET utf8mb4;`
2. 启动：`.\mvnw.cmd spring-boot:run`
3. 访问：http://localhost:8080

### Docker 运行

```powershell
docker compose up --build
```

访问：http://localhost:8080

### 默认账号

| 角色 | 用户名 | 密码 | 用途 |
|---|---|---|---|
| 普通玩家 | student | student123 | 体验完整游戏流程 |
| 管理员 | admin | admin123 | 管理事件数据 |

## 玩家指南

### 注册与登录

1. 打开 http://localhost:8080，自动跳转到登录页。
2. 首次使用点击"注册"，填写用户名和密码。
3. 注册成功后返回登录页，输入账号密码登录。

### 创建角色

首次登录后需要创建角色，填写以下信息：

| 字段 | 说明 | 可选项 |
|---|---|---|
| 角色名 | 你在游戏中的名字 | 自由输入 |
| 年级 | 当前年级 | 大一 / 大二 / 大三 / 大四 |
| 专业类型 | 影响初始属性倾向 | 计算机类 / 电子信息类 / 通用 |
| 成长路线 | **核心选择**，影响初始属性和路线倾向 | 考研 / 就业 / 竞赛 / 六边形 / 摆烂 |

**成长路线对比**：

| 路线 | 特点 | 初始优势 | 适合玩法 |
|---|---|---|---|
| 📚 考研路线 | 学业和自律较高，压力略高 | 学业 70，自律 55 | 去图书馆学习，探索学术路线 |
| 💼 就业路线 | 社交和技能均衡，压力低 | 社交 55，技能 50 | 参加组织、挑战副本、积累技能 |
| 🏆 竞赛路线 | 技能突出，压力中等 | 技能 52，学业 65 | 去实验室，刷副本拿高分 |
| ⬡ 六边形路线 | 各属性均衡，无明显短板 | 全部 53+ | 什么都尝试，均衡发展 |
| 🛋️ 摆烂求生路线 | 压力极低，但学业和自律偏低 | 压力 20，健康 80 | 休闲体验，看能撑到什么结局 |

### 仪表盘

登录并创建角色后，进入仪表盘（寝室主界面）。这是你的"大本营"。

顶部信息栏显示：
- **当前周次**：第 X 周 / 共 16 周
- **行动点（AP）**：本周剩余可用的行动点
- **压力值**：当前压力等级

主界面区域显示：
- **属性面板**：7 维属性条（学业/健康/金钱/社交/技能/压力/自律）
- **周主题**：当前阶段主题名称和行动建议
- **路线倾向**：系统根据你的属性推导的成长方向
- **阶段进度条**：6 阶段高亮当前阶段
- **熟人列表**：已认识的 NPC，显示熟悉度和关系阶段
- **成就称号**：当前装备的称号

底部导航栏（Dock）可快速跳转：
- 🏠 寝室（仪表盘）
- 🗺️ 校园地图
- 🔍 探索
- 📋 周总结

### 校园地图与事件

点击 Dock 中的"校园地图"进入地图页。

地图页顶部展示莲花街校区真实地图，有 8 个可点击热点。下方是地点卡片列表。

**8 个校园地点**：

| 地点 | 特色 | 解锁内容 |
|---|---|---|
| 🏫 教学楼 | 上课、点名、课堂事件 | 基础学习事件 |
| 📚 图书馆 | 自习、抢座、期末复习 | 隐藏事件（探索度 40/60/80）、组织"计算机协会" |
| 🏠 宿舍 | 休息、赶 DDL、室友互动 | 生活事件 |
| 🍜 食堂 | 吃饭、控制预算 | 生活事件、社交事件 |
| 🏃 操场 | 运动、体测 | 健康事件、副本"体测生存挑战" |
| 🔬 实验室 | 写代码、做实验 | 隐藏事件、组织"实验室项目组" |
| 🎪 社团活动区 | 招新、活动 | 社交事件、多个组织 |
| 📦 快递站 | 取快递、排队 | 生活事件 |

点击地点卡片或地图热点进入地点详情，可以看到：
- 地点描述和探索度
- 可触发的随机事件（点击"探索事件"触发）
- 有"有传闻"标记的地点表示本周有可利用的情报

**事件选择**：

进入事件后，你会看到场景描述、氛围标签和 2-3 个选项。每个选项标注风险等级：

| 风险等级 | 含义 | 颜色 |
|---|---|---|
| 🟢 low | 低风险，收益稳定 | 绿色 |
| 🟡 medium | 中等风险，收益和风险并存 | 黄色 |
| 🔴 high | 高风险，可能翻车但可能大赚 | 红色 |

选择后会展示结果文案和属性变化（如"学业 +3，压力 +2，经验 +28"）。

### 探索校园

点击 Dock 中的"探索"进入探索页。

探索页展示所有 8 个地点，每个地点显示当前探索度。点击"开始探索"消耗 1 AP，随机增加探索度并获得探索结果。

**探索结果类型**（12 种）：

| 类型 | 说明 |
|---|---|
| 📖 学业发现 | 学业 +1 ~ +3 |
| 💻 技能提升 | 技能 +1 ~ +3 |
| 🤝 社交机会 | 社交 +1 ~ +2 |
| 💪 健康恢复 | 健康 +1 ~ +2 |
| 💰 捡到钱 | 金钱 +1 ~ +3 |
| 😰 压力事件 | 压力 +1 ~ +3 |
| 📢 发现传闻 | 获得一条可利用的传闻 |
| 👤 遇见 NPC | 随机遇到一个 NPC |
| 🔗 奇遇触发 | 推进探索奇遇链 |
| ⭐ 搭子加成 | 本周搭子提供额外属性加成 |
| 🆘 搭子救场 | 高压力时搭子出手相救，压力 -2 |
| 🎯 探索度提升 | 探索度 +5 ~ +15 |

**探索结果页还会展示"本次影响来源"**，告诉你这次探索受到了哪些因素影响（周主题加成、传闻效果、搭子外溢等）。

**探索度阈值**：

| 探索度 | 解锁内容 |
|---|---|
| 40+ | 该地点的隐藏事件解锁 |
| 60+ | 更多隐藏事件解锁 |
| 80+ | 全部隐藏事件解锁 |

### NPC 互动

**遇见 NPC**：探索地点时有 35% 概率随机遇见一个 NPC。遇见后会显示 NPC 的倾向提示（如"和 TA 在一起学业容易进步"）。

**NPC 列表**：

| NPC | 地点 | 性格 | 特殊互动 |
|---|---|---|---|
| 阿杰（室友） | 宿舍 | 随和 | 基础互动 + 莲花街互动 |
| 林然（学霸） | 教学楼/图书馆 | 内向 | 学习相关互动 |
| 周予（社牛） | 社团活动区/食堂 | 外向 | 社交相关互动 |
| 老郑（师兄） | 实验室 | 稳重 | 技术相关互动 |
| 小马（运动搭子） | 操场 | 活泼 | 健康相关互动 |
| 富少 | 实验室 | 话多 | 莲花街互动 |
| 小鱼 | 图书馆 | 安静 | 莲花街互动 |
| 柳如烟 | 社团活动区 | 神秘 | 莲花街互动 |

**主动互动**：

从仪表盘的"熟人列表"点击 NPC 头像进入 NPC 详情页，可以：
- 查看熟悉度、关系阶段（陌生→点头之交→熟人→好友→知己）
- 查看故事进度
- 选择互动选项（消耗 1 AP，每周对同一 NPC 最多互动 1 次）
- 如果故事进度达标，解锁"专属分支互动"

**本周搭子**：

每周可选择 1 名熟悉度 ≥ 50 的 NPC 作为"本周搭子"。搭子效果：
- 在搭子归属地点探索时获得稳定属性加成
- 高压力（≥ 60）时有概率触发"搭子救场"，压力 -2
- 与搭子互动时获得额外熟悉度加成

**8 个组织**：

| 组织 | 类型 | 解锁地点 | 探索门槛 | 推荐属性 |
|---|---|---|---|---|
| 学生会 | 学生组织 | 社团活动区 | 0 | social |
| 实验室项目组 | 技术社团 | 实验室 | 10 | skill |
| 篮球社 | 兴趣社团 | 操场 | 5 | health |
| 计算机协会 | 技术社团 | 实验室 | 15 | skill |
| 信息学院学生会 | 学生组织 | 社团活动区 | 20 | social |
| 信息学院辩论队 | 竞赛队 | 社团活动区 | 25 | social |
| 轮滑社 | 兴趣社团 | 操场 | 10 | health |
| 校合唱团 | 文艺社团 | 社团活动区 | 20 | social |

**组织流程**：

1. **发现**：到达组织所在地点，探索度达到门槛后，组织出现在列表中。
2. **加入**：需要满足社交值要求（开学适应周降低 5 点），点击"加入"。
3. **活动**：每周消耗 AP 参加组织活动，获得贡献值 + 声望 + 属性变化 + 经验。
4. **晋升**：贡献值和声望达到一定数值后自动晋升职位。

### 副本挑战

从 Dock 导航进入副本页（挑战海报墙）。

**4 个副本**：

| 副本 | 类型 | 阶段数 | 特色 |
|---|---|---|---|
| Java 课设：DDL 前夜 | 课程 | 3 | 需求风暴 → 数据库拼图小游戏 → Bug 定位小游戏 |
| 体测生存挑战 | 体能 | 3 | 1000 米配速 → 引体向上排队 → 坐位体前屈补救 |
| 小组作业 | 团队 | 5 | 公布名单 → 线上开会 → 各自开荒 → 整合攻坚 → 卡点提交 |
| 莲花街体测挑战 | 体能 | 3 | 莲花街校区版体测 |

**副本流程**：

1. **封面页**：查看副本介绍、难度、推荐属性。
2. **开始挑战**：进入第一阶段。
3. **阶段选择**：每阶段有 3 个选项（风险/收益不同），或触发小游戏。
4. **阶段结算**：根据选择计算分数、属性变化、压力变化。
5. **最终评价**：所有阶段完成后获得最终评价（如"课设战神"）。

**小游戏**：

- **数据库拼图**：选择正确的表关系（有计时，技能越高时间越长）。
- **Bug 定位**：5 题随机抽 3，找出代码中的 Bug（技能影响可用时间）。

### 周总结与推进

每周行动结束后，从仪表盘点击"推进周次"进入周总结页。

周总结展示：
- **周主题**：当前阶段主题名称和描述
- **阶段提示**：当前阶段剩余周数
- **目标状态**：本周选定目标的完成情况（完成可领取奖励）
- **属性快照**：本周属性变化
- **NPC 熟人**：已认识的 NPC 列表
- **近期成就**：新解锁的成就
- **本周影响回放**：本周探索触发的各种影响来源
- **评价文案和评级**：系统对你本周表现的综合评价

点击"推进到下一周"执行周结算，进入下一周。第 16 周推进后进入学期结局。

### 学期结局

16 周结束后，进入学期结局页。

结局页展示：
- **结局名称和图标**：你获得的结局
- **结局描述**：结局故事文案
- **路线评分卡片**：
  - 路线画像（你的成长方向）

**12 种结局**（7 基础 + 5 路线隐藏）：

基础结局（按属性条件匹配）：

| 结局 | 触发条件 |

## 游戏机制详解

### 属性系统

7 维属性，范围 0-100：

| 属性 | 图标 | 含义 | 影响 |
|---|---|---|---|
| 学业 | 📚 | 你的学习能力和成绩水平 | 影响学习事件结果、学业路线倾向、结局匹配 |
| 健康 | 💚 | 身体状况和精力 | 压力 > 80 时每周 -3；健康 < 20 时下周 AP -1 |
| 金钱 | 💰 | 经济状况 | 影响部分事件选项的可用性 |
| 社交 | 🤝 | 人际关系和沟通能力 | 影响组织加入、社交事件结果、社交路线倾向 |
| 技能 | 💻 | 实践和技术能力 | 影响副本小游戏时间、技能路线倾向、结局匹配 |
| 压力 | 😰 | 心理压力（越高越差） | 每周自然 -5；> 80 损害健康；影响结局匹配 |
| 自律 | 📋 | 自我管理能力 | 影响学业评分、自律路线倾向 |

### 成长路线

创建角色时选择，影响初始属性和路线倾向推导的一致性 bonus。详见上方"创建角色"部分的路线对比表。

### 学期阶段

16 周学期分为 6 个阶段，每个阶段有不同的事件偏向和机制加成：

| 阶段 | 周数 | 主题 | 特色 |
|---|---|---|---|
| 🎒 开学适应 | 1-2 | 新生适应期 | NPC 互动熟悉度额外 +1，组织加入社交门槛降低 |
| 🎉 节奏建立 | 3-5 | 社团活跃期 | 参加组织活动贡献和声望额外 +1 |
| 📚 期中波动 | 6-8 | 考试逼近 | 教学楼/图书馆/实验室探索获得学业加成 |
| 🧭 路线分化 | 9-11 | 成长分化 | 图书馆/实验室/惟学楼探索获得技能加成 |
| ⏰ 项目与 DDL | 12-14 | 课设高压期 | 副本结算压力额外 +1 |
| 🏁 期末与体测 | 15-16 | 冲刺期 | 图书馆/操场探索收益增强，体测副本压力缓冲 |

### 行动点（AP）

每周 4 个行动点（可通过配置修改），所有行动消耗 AP：

| 行动 | AP 消耗 |
|---|---|
| 探索地点 | 1 |
| 主动 NPC 互动 | 1 |
| 参加组织活动 | 1（或组织设定值） |
| 触发地图事件 | 0（事件不消耗 AP，但需要先探索到达） |
| 副本阶段 | 0（进入副本后不额外消耗 AP） |

AP 在每周推进后自动恢复。

### 周结算规则

每次推进到下一周时自动执行：

1. **压力检查**：检查是否完成了"压力保持"周目标
2. **周次 +1**，AP 恢复满
3. **学期阶段更新**
4. **高压惩罚**：压力 > 80 → 健康 -3
5. **低血惩罚**：健康 < 20 → 下周最大 AP -1（最低 2）
6. **自然减压**：压力 -5（无条件）

### 传闻与影响来源

每周系统为你抽取 2-3 条传闻（基于你的 ID 和周次，稳定可复现）。传闻出现在仪表盘和地图页。

传闻类型和效果：

| 类型 | 效果 | 说明 |
|---|---|---|
| `explore_bonus` | 探索度加成 | 探索对应地点时额外增加探索度 |
| `npc_boost` | NPC 加成 | 提升 NPC 遇见概率 +10%，探索反馈社交 +1 |
| `event_hint` | 事件偏向 | 地图事件更偏向对应类型（+30 权重） |
| `safe_zone` | 安全保护 | 探索时减少负面结果概率 |
| `attr_bonus` | 属性加成 | 探索时获得额外属性变化 |

### 路线倾向

系统根据你的当前属性实时推导成长路线倾向，显示在仪表盘和周总结中。

5 种倾向：学业路线、社交路线、技能路线、稳定生活路线、均衡路线。

倾向不仅用于展示，还影响**周目标选择**——系统会根据你当前的阶段和路线倾向，优先推荐相关类型的周目标。

### 结局评分

学期结算时计算 5 维评分（0-100 分）：

| 维度 | 评级 |
|---|---|
| ≥ 80 | 🟢 优秀 |
| ≥ 60 | 🟡 良好 |
| ≥ 40 | 🟠 一般 |
| < 40 | 🔴 不足 |

评分由属性、探索度、组织贡献、NPC 关系、副本完成数和周目标完成数综合决定。评分展示在结局页的"路线评分卡片"中。

## 常见问题

### Q: 行动点用完了怎么办？

A: 点击仪表盘的"推进到下一周"进入周总结，推进后 AP 会恢复。你也可以在 AP 用完之前推进。

### Q: 压力太高了怎么办？

A: 压力每周自然降低 5 点。选择低风险事件选项、去操场探索、完成体测副本都可以帮助减压。压力 > 80 时每周健康 -3，要特别注意。

### Q: 为什么有些事件看不到？

A: 部分事件需要探索度达到门槛（40/60/80）才会解锁。多去对应地点探索提升探索度。

### Q: 如何加入组织？

A: 先到达组织所在地点，探索度达到要求后组织会出现在组织列表中，然后满足社交值要求即可加入。

### Q: NPC 互动为什么提示"本周已互动"？

A: 每个 NPC 每周最多主动互动 1 次，下周一自动重置。可以先去探索提升熟悉度，熟悉度越高解锁的互动越多。

### Q: 搭子有什么用？

A: 选择搭子后，在搭子归属地点探索会获得稳定加成。高压力时还有概率触发"搭子救场"（压力 -2）。每周只能选 1 个搭子，需要熟悉度 ≥ 50。

### Q: 学期结束后怎么办？

A: 学期结束后可以"重开新学期"，保留成长路线选择，重置属性、探索度、组织关系等，开始新的 16 周学期。

### Q: Docker 运行时 8080 端口被占用？

A: 先停止本地运行的 Spring Boot 应用，再执行 `docker compose up --build`。

### Q: 如何退出 Docker？

A: 执行 `docker compose down`。如果要清除所有数据（包括 MySQL 数据），执行 `docker compose down -v`。
