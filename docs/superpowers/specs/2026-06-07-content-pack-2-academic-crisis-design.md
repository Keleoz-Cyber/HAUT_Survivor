# Content Pack 2: 考试周与 DDL 生存线设计

## 1. 设计目标

本次内容包的目标是让 HAUT Survivor 从“有多个功能入口的校园模拟 Demo”进一步变成“每一周都像在真实大学生活里求生”的养成游戏。

当前项目已经具备周回合、行动点、地图事件、探索、组织、副本、NPC、周目标、成就和周总结。第二包不应该再只堆叠普通事件，而应围绕一个清晰主题建立中期节奏：课程压力、考试预警、课设 DDL、体测冲刺共同挤压玩家的行动点和属性状态。

核心体验目标：

- 玩家在第 3 周明显感到 DDL 和复习压力上升。
- 玩家需要在“复习、摆烂、求助、赶工、社交、休息”之间做取舍。
- NPC、传闻、周目标、副本、成就和周总结能围绕学业危机互相呼应。
- 新增内容仍保持 Demo 可控范围，不引入完整 GPA、课程表、挂科重修等大型系统。

## 2. 范围边界

### 本次要做

- 新增一组考试周 / DDL 主题事件。
- 新增一个学业危机主题副本。
- 新增若干周目标、成就、传闻。
- 增强 NPC 在学业危机中的参与感。
- 增强周总结对本周学业表现的反馈。
- 保持 UI 2.0 现有结构，只补必要文案和展示，不做大规模视觉重构。

### 本次不做

- 不做完整课程表。
- 不做 GPA / 学分 / 挂科 / 重修系统。
- 不做复杂考试分数计算。
- 不做长期多学期课程链。
- 不新增大型前端框架。
- 不重构现有核心表结构，除非实现时发现当前字段确实无法表达必要数据。

## 3. 周节奏设计

第二包围绕 4 周 Demo 学期建立更强主题节奏。

### 第 1 周：开学适应

主题感：刚开学，作息混乱，课程还没有真正压下来。

内容方向：

- 早八点名。
- 选课群消息轰炸。
- 寝室作息磨合。
- 图书馆座位初体验。
- 室友阿杰约你开黑。

主要取舍：

- 自律 vs 压力。
- 社交 vs 学业。
- 休息 vs 提前准备。

### 第 2 周：小测预警

主题感：老师开始暗示“下周要测”，学生开始分化。

内容方向：

- 课代表突然发复习范围。
- 学霸林然整理资料。
- 社团招新和课程小测撞车。
- 实验室师兄老郑提醒你课设别拖。

主要取舍：

- 加入组织 vs 复习准备。
- 求助 NPC vs 自己硬学。
- 暂时放松 vs 提前防爆。

### 第 3 周：DDL 高压

主题感：Java 课设、数据库、Bug、汇报、作业一起爆。

内容方向：

- 组队分工失控。
- Git 合并冲突。
- 数据库设计返工。
- Bug 暴走。
- 半夜宿舍赶工。
- 图书馆抢座复习。

主要取舍：

- 技能硬刚 vs 找师兄。
- 牺牲健康熬夜 vs 降低完成质量。
- 稳妥交付 vs 冒险冲高评价。

### 第 4 周：期末与体测结算

主题感：复习、体测、报告、最后一波组织活动同时收束。

内容方向：

- 考前抱佛脚。
- 操场体测冲刺。
- 课程报告最后修改。
- 社团/组织活动收尾。
- 周总结文案更像“学期最后一口气”。

主要取舍：

- 学业冲刺 vs 健康维持。
- 压力控制 vs 经验/奖励最大化。
- 当前结局路线收束。

## 4. 新增事件设计

建议新增 24 条事件，分布如下：

| 周次 | 建议数量 | 重点地点 |
|---|---:|---|
| 第 1 周 | 4 | 教学楼、宿舍、食堂、图书馆 |
| 第 2 周 | 6 | 教学楼、图书馆、社团区、实验室 |
| 第 3 周 | 8 | 实验室、宿舍、图书馆、教学楼 |
| 第 4 周 | 6 | 教学楼、操场、图书馆、实验室 |

事件原则：

- 每个事件给 2-3 个系统预设选项。
- 选项应体现策略差异，不要只是“好 / 中 / 坏”。
- 至少一部分选项需要高技能、高自律、低压力或 NPC 熟悉度作为叙事依据，但 MVP 阶段可以先通过文案暗示，不强制做复杂判定。
- 压力上升要谨慎，避免玩家一两次选择就爆表。
- 结果文案要像校园生活，不要像系统提示。

### 事件示例

#### 早八点名危机

地点：教学楼  
周次：第 1 周  
情境：闹钟响了三次，你终于在距离上课还有 12 分钟时醒来。群里有人说老师今天可能点名。

选项：

- 直接冲刺去教室：健康 -1，压力 +3，自律 +2，学业 +2。
- 让室友帮忙占座：社交 +1，压力 +1，学业 +1。
- 继续睡，赌一手不点名：健康 +2，自律 -3，学业 -2，压力 -1。

#### 课代表发来复习范围

地点：图书馆  
周次：第 2 周  
情境：课代表突然在群里发了 8 页 PDF，说“老师说这些都可能考”。

选项：

- 立刻整理复习计划：学业 +4，自律 +3，压力 +2。
- 找林然借资料：学业 +3，社交 +2，压力 -1。
- 先收藏，晚上再看：压力 -1，自律 -2，学业 +1。

#### Git 合并地狱

地点：实验室  
周次：第 3 周  
情境：你拉取队友代码后，项目出现 37 个冲突。控制台红得像期末成绩单。

选项：

- 冷静逐个处理冲突：技能 +5，自律 +2，压力 +4。
- 找师兄老郑救场：技能 +3，社交 +1，压力 -2。
- 直接复制旧版本覆盖：压力 -3，技能 -2，学业 -2，可能获得“技术债”标签。

#### 考前抱佛脚

地点：图书馆  
周次：第 4 周  
情境：距离考试还有一晚，你终于翻开了那本像新买的一样的教材。

选项：

- 只看高频题型：学业 +4，压力 +3，自律 +1。
- 跟林然一起过重点：学业 +5，社交 +1，压力 +1。
- 放弃挣扎，早点睡：健康 +3，压力 -3，学业 -2。

## 5. 新增副本设计

推荐新增副本：`数据库课设答辩夜`

理由：

- 与 Java 课设已有副本相关，但不重复。
- 能自然结合数据库设计、ER 图、SQL、答辩、组队协作。
- 比单纯考试更适合做阶段任务和小游戏。

### 副本结构

副本名称：数据库课设答辩夜  
类型：DDL / 学业危机  
难度：中等偏高  
预计时间：8-10 分钟  
推荐属性：技能、自律、学业  
奖励称号：表结构守夜人

阶段 1：需求梳理

- 情境：老师要求系统必须有用户、任务、记录、统计四类核心数据。
- 玩法：单选策略。
- 重点：选择“先列实体和关系”比“直接建表”更好。

阶段 2：ER 图连线

- 情境：你需要把用户、任务、副本记录、属性变化连起来。
- 玩法：复用或扩展现有数据库拼图小游戏。
- 重点：关系选择正确度影响评分。

阶段 3：SQL 暴走

- 情境：答辩前一晚，外键、字段名、时间类型同时报错。
- 玩法：Bug 定位小游戏或选项式排错。
- 重点：技能值可提供加成。

阶段 4：答辩现场

- 情境：老师问“为什么这里要拆表？”
- 玩法：单选策略 + 属性判定。
- 重点：学业/技能/压力共同影响评价。

### 副本评价

评价分为：

- 优秀：结构清晰，答辩稳定，获得较高技能和学业奖励。
- 通过：基本能跑，解释略虚，获得中等经验。
- 惊险通过：现场修表，压力下降但奖励较少。
- 翻车：Demo 能启动但答辩被追问，获得少量经验和压力变化。

MVP 可以先不做真正失败阻断，仍允许推进，但结算文案和奖励不同。

## 6. 周目标扩展

新增 3-4 个周目标即可，不要一次性塞太多。

建议：

| goal_key | 名称 | goal_type | 目标 | 奖励 |
|---|---|---|---:|---|
| study_twice | 复习两小时 | academic_event | 2 | 经验 +35，学业 +3 |
| ddl_survivor | DDL 幸存 | dungeon_stage | 2 | 经验 +45，技能 +4 |
| keep_calm_exam | 稳住别炸 | pressure_keep | 55 | 经验 +40，压力 -6 |
| ask_for_help | 会求助也是本事 | npc_meet | 1 | 经验 +30，社交 +3 |

如果当前 `WeeklyGoalService` 不支持 `academic_event`，实现时可以先复用现有类型，或新增一个轻量 goal_type，并在相关事件选择后更新。

## 7. 成就扩展

建议新增 5 个成就：

| achievement_key | 名称 | 条件 | 称号 |
|---|---|---|---|
| early_class_warrior | 早八战士 | 完成早八相关事件优秀选项 | 早八幸存者 |
| ddl_survivor_plus | DDL 幸存者 | 完成数据库课设答辩夜 | 表结构守夜人 |
| last_minute_master | 抱佛脚大师 | 第 4 周完成考前复习事件 | 考前冲刺型选手 |
| calm_under_pressure | 高压稳定器 | 高压周压力仍低于阈值 | 情绪稳定大师 |
| help_seeker | 会求助的人 | 通过 NPC 帮助解决学业事件 | 不单打独斗 |

注意：

- 不建议新增太多需要复杂统计的成就。
- 能通过现有触发点直接 unlock 的优先。
- 如果条件需要累计，优先接入 `AchievementService.unlockIfEligible()`。

## 8. 传闻扩展

新增 8-12 条传闻，围绕学业危机提供氛围和轻提示。

示例：

- 图书馆三楼靠窗的位置，复习效率据说特别高。
- 数据库老师最近很爱问“为什么要拆表”。
- 实验室今晚有人通宵改 Bug。
- 操场体测队伍下午会变短。
- 食堂二楼的热汤能救一半熬夜灵魂。
- 林然整理了一份复习提纲，但只发给熟人。
- 老郑说课设不要最后一天才合并代码。
- 室友阿杰正在招募“复习五分钟，开黑两小时”小队。

MVP 阶段传闻仍以展示为主。后续可以让传闻影响地点事件概率或选项收益。

## 9. NPC 参与方式

NPC 不需要马上做完整支线，但要让他们在学业危机里更像“人”。

### 室友阿杰

定位：摆烂诱惑 + 寝室陪伴。

事件表现：

- 可能劝你开黑放松。
- 熟悉度高时会帮你叫醒早八。
- 高压周可能递给你泡面。

### 学霸林然

定位：复习辅助。

事件表现：

- 提供复习提纲。
- 帮你抓重点。
- 熟悉度高时降低考前事件压力。

### 社牛周予

定位：信息渠道。

事件表现：

- 告诉你哪个老师点名严格。
- 帮你找到组队成员。
- 牺牲一点自律，换取社交和机会。

### 师兄老郑

定位：课设救场。

事件表现：

- 指导 Git 冲突。
- 提醒数据库设计风险。
- 熟悉度高时在副本中提供较好选项或更低压力。

### 运动搭子小马

定位：体测和健康平衡。

事件表现：

- 约你跑步降压。
- 第 4 周体测前提供健康加成。
- 帮玩家从“只学不动”的状态拉回来。

## 10. 周总结增强

当前周总结已经能显示周主题、目标、属性、NPC、成就、评价和评级。第二包建议增加“学业危机评价”文案，不一定新增字段。

可在 `WeekSummaryServiceImpl` 中根据当前周、学业、技能、压力、周目标完成情况生成补充评价。

示例文案：

- 你把 DDL 压成了可控范围，这周的你像一个会呼吸的任务管理器。
- 你完成了复习计划，但压力已经快把寝室台灯照穿了。
- 这周你没有完全解决学业危机，但至少知道下周不能再拖。
- 你靠 NPC 和队友活了下来，大学不是单机游戏。
- 你选择早点睡，学业没冲到最高，但人还活着。

## 11. 数据与实现建议

### 优先复用现有表

优先使用：

- `event`
- `event_option`
- `dungeon`
- `dungeon_task`
- `dungeon_task_option`
- `weekly_goal`
- `achievement`
- `rumor`
- `npc`
- `user_npc_relation`

### 可能需要轻量扩展

如果要统计“学业事件完成次数”，可以考虑：

- 方案 A：复用现有 weekly goal 类型，不新增字段。
- 方案 B：新增 `academic_event` goal_type，并在相关事件选择后调用 `weeklyGoalService.updateProgress()`。
- 方案 C：只通过副本阶段和探索次数间接表达，避免新增逻辑。

推荐先选 B，但实现要小心测试覆盖。

### 不建议本轮新增表

本轮不建议新增 `course`、`exam`、`grade` 等表。它们会把项目带向完整教务模拟，不符合当前 Demo 节奏。

## 12. UI 要求

本轮不做 UI 大改，但新增内容要符合 UI 2.0 语气。

要求：

- 事件选项要像行动决策，不要像表单按钮。
- 副本阶段文案要有场景感。
- 周总结新增文案要像回忆报告，不要像日志。
- 新增按钮或提示不应破坏移动端 Dock。
- 如果新增副本页面使用现有 `dungeon` 模板即可，不要额外做一套独立样式。

## 13. 测试计划

至少新增或更新以下测试：

- Seed 数据 smoke：确认新增事件、传闻、成就、副本数据存在。
- DungeonServiceTests：确认新副本阶段和选项可正常推进。
- WeeklyGoalServiceTests：如新增 `academic_event`，验证进度更新和奖励领取。
- AchievementServiceTests：验证新增成就可解锁。
- WeekSummaryServiceTests：验证高压周能生成学业危机评价。
- Controller 冒烟：确认 dashboard、map、dungeon、week summary 不出现模板错误。

完整验收命令：

```powershell
.\mvnw.cmd clean test
```

## 14. 验收标准

实现完成后应满足：

- 新增至少 20 条学业危机相关事件。
- 新增至少 1 个完整副本，包含 3-4 个阶段。
- 新增至少 3 个周目标。
- 新增至少 5 个成就。
- 新增至少 8 条传闻。
- NPC 在至少 5 条新增事件或副本文案中被明确使用。
- 第 3 周 DDL 高压感明显增强。
- 周总结能反馈本周学业危机处理情况。
- 移动端页面无明显 Dock 遮挡。
- `.\mvnw.cmd clean test` 全部通过。
