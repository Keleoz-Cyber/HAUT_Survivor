# 06. UI, UX And Visual Design

## 设计目标

界面目标不是做复杂游戏 UI，而是让课程设计 Demo 看起来不像普通后台管理系统。

用户进入系统后应感到：

- 自己在一个校园生存模拟系统中；
- 不同地点有不同氛围；
- 事件和副本有故事性；
- 属性变化可见；
- 操作结果有反馈；
- 可以继续探索。

### 管理员端页面

建议页面：

1. 管理员首页；
2. 用户管理；

4. 事件管理；

Demo 阶段不需要全部完成，优先保证学生端体验。

## 仪表盘设计

仪表盘应展示角色状态和下一步入口。

建议模块：

- 角色名、年级、专业、成长路线；
- 等级、经验；
- 属性条；
- 当前压力提醒；
- 今日推荐地点；
- 最近事件结果；
- 核心副本入口；
- 普通任务摘要。

设计原则：

- 信息紧凑但不要像后台；
- 属性条比纯数字更直观；
- 给用户明确下一步行动按钮；
- 避免大段说明文字。

## 校园地图设计

地图页面应从“地点列表”升级为“莲花街校区行动地图”。

基础版可用卡片式地图：

```text
[属性状态栏]

[教学楼] [图书馆] [宿舍] [食堂]
[操场] [实验室] [社团活动区] [快递站]

[核心副本入口：Java 课设：DDL 前夜]
```

每个地点卡片建议包含：

- 地点名称；
- 地点图标；
- 一句氛围描述；
- 主要影响属性；
- 可能事件类型；
- 行动按钮。

视觉建议：

| 地点 | 视觉方向 |
|---|---|
| 教学楼 | 明亮、课堂、早八 |
| 图书馆 | 安静、座位灯、书本、低电量电脑 |
| 宿舍 | 暗色电脑光、床铺、桌面 |
| 食堂 | 暖色、餐盘、排队、夜宵 |
| 操场 | 开阔、跑道、体测 |
| 实验室 | 深色代码屏、终端、课设压力 |
| 社团活动区 | 活动海报、人群、招新 |
| 快递站 | 包裹、雨天、排队 |

## 事件页设计

事件页是游戏感的关键。

建议结构：

```text
[地点/事件类型标签]
[事件标题]
[情境描述]
[当前属性摘要]

[选项 A：处理方式 + 风险提示]
[选项 B：处理方式 + 风险提示]
[选项 C：处理方式 + 风险提示]
```

选项展示建议：

- 不要只写“选项 A/B/C”；
- 每个选项显示一句行动；
- 可用小标签提示倾向，例如“稳妥”“冒险”“摆烂”“求助”；
- 不要直接完全暴露所有数值变化，Demo 可以显示部分提示。

结果页应展示：

- 选择结果；
- 属性变化；
- 经验变化；
- 一句有记忆点的反馈；
- 回地图或进入副本按钮。

## 副本页设计

副本页要比普通事件更有阶段感。

副本列表页：

- 展示副本名称；
- 展示预计时长；
- 展示推荐属性；
- 展示难度；
- 展示通关状态；
- 当前 Demo 核心副本要明显突出。

副本阶段页：

- 当前阶段名称；
- 副本进度，例如 1/3；
- 阶段情境；
- 当前总分；
- 当前属性摘要；
- 任务操作区；
- 下一步按钮。

副本结算页：

- 阶段评价；
- 阶段结果文案；
- 本阶段得分；
- 副本总分；
- 属性变化；
- 如果副本完成，显示最终评价和过程标签。

## 小游戏设计原则

小游戏只作为短互动，不要做成大型游戏。

要求：

- 30-90 秒内完成；
- 后端负责结算；
- 失败也能推进，但评价和后果不同；
- 与项目主题相关；
- 能在答辩时解释其业务意义。

推荐小游戏：

| 小游戏 | 玩法 | 适用场景 |
|---|---|---|
| 数据库连线/拼图 | 选择或连接正确表关系 | Java 课设 |
| Bug 定位 | 根据报错选择原因 | Java 课设、面试 |
| 复习排序 | 将复习重点排序 | 期末周 |
| 体测节奏条 | 在合适区间点击 | 体测 |
| 快问快答 | 2-3 道选择题 | 答辩、面试 |

## 视觉素材策略

短期不需要找真实版权图片。可以先用以下方式：

1. CSS 渐变和主题色；
2. 图标和 emoji 风格符号；
3. 简单背景图或 AI 生成图；
4. 地点卡片插画；
5. 副本氛围图。

优先补视觉的页面：

1. 校园地图页；
2. 事件页；
3. Java 课设副本页；
4. 副本结算页；
5. 仪表盘。

## 风格控制

不要做成纯后台风格：

- 避免大量表格作为主体验；
- 避免所有页面白底灰边；
- 避免所有按钮都是普通 Bootstrap 默认样式；
- 避免把说明文字堆满屏幕。

也不要过度游戏化：

- 不做复杂 3D；
- 不做大量动画；
- 不做影响课程设计严肃性的玩笑；
- 不引入难以维护的大型前端框架。

整体风格建议：

- 校园生活感；
- 轻量 RPG 属性面板；
- 情境卡片；
- 地点氛围；
- 清晰反馈。
