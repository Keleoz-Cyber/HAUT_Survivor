## 小游戏素材

### 数据库拼图

适用：Java 课设副本。

玩法：

```text
用户在若干候选关系中选择正确关系。
后端根据正确数、错误数、用时、技能值和前置标签结算。
```

正确关系：

- `user -> player_attribute`
- `event -> event_option`
- `dungeon -> dungeon_task`

错误干扰项：

- `user -> event`
- `task -> event_option`
- `campus_location -> player_attribute`

### Bug 定位

适用：Java 课设、实习面试。

玩法：

```text
系统展示简化报错或异常现象。
用户选择最可能原因。
后端按选择正确性、技能值、压力值和副本标签结算。
```

题库候选：

| 异常现象 | 正确原因 | 干扰项 |
|---|---|---|
| 访问提交后 404 | 表单 action 或 Controller 路径不一致 | 密码错误、CSS 未加载 |
| 页面有数据但字段为空 | 实体字段和数据库列映射不一致 | 端口被占用、浏览器缓存 |
| Mapper 无法注入 | Mapper 未扫描或注解缺失 | SQL 写错、图片路径错 |
| 启动失败提示端口占用 | 旧进程仍在运行 | 密码错误、模板语法错 |
| 选择事件后属性没变 | Service 未应用选项属性变化 | 图片缺失、导航栏错误 |
